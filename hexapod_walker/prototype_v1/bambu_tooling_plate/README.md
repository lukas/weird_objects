# Tooling plate -- Bambu X1 / X1 Carbon plate

Bed: **256 x 256 x 256 mm**.  Single part, dropped flat on the bed and centred.

- `tooling_plate.3mf` -- preferred import (opens already positioned)
- `tooling_plate.stl` -- same geometry, plain STL

## Geometry
- 110 mm flat-to-flat hex (corners 63.5 mm) x 4.0 mm
- footprint 110 x 127 x 4.0 mm
- 29 M3 grid holes, 2 through slots
- 12 standoff columns (octagon)

## Print notes
- PLA or PETG, 0.2 mm layers, 3+ walls, 30-40% infill.
- No supports (flat plate, all cuts vertical).
